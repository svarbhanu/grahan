# @grahan/calendars

World calendars for the [grahan](https://github.com/svarbhanu/grahan) sky
engine — Bikram Sambat (the Nepali civil calendar) first; Hijri, Hebrew, and
Chinese lunisolar planned. Zero dependencies beyond `@grahan/core`.

Bikram Sambat month lengths are set by Nepal's calendar authority, not by a
formula, so this package ships committed month-length tables (BS 1975–2100,
≈ AD 1918–2044) verified against published calendars, and converts both
directions with exact day-count arithmetic.

_Bikram Sambat conversion API lands in the next commits; see the repo README
for the roadmap._
